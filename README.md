# Unity Öğrenme Platformu

Unity ve C# eğitimlerini canlı ders, etkileşimli alıştırma, proje geliştirme, ödev ve düzenli tekrarlarla bir araya getiren çok öğrencili eğitim platformu.

İlk çalışan ürün dilimi; ortak giriş akışını, rol bazlı öğrenci ve admin panellerini, admin tarafından öğrenci hesabı oluşturmayı, örnek öğrenme yolunu, güvenli C# kural denetimini ve PWA kabuğunu içerir. Firebase bağlantısı gelene kadar veri erişimi değiştirilebilir bir tanıtım adaptörü üzerinden yürür.
