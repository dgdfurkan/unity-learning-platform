# Unity Öğrenme Platformu

Unity ve C# eğitimlerini canlı ders, etkileşimli alıştırma, proje geliştirme, ödev ve düzenli tekrarlarla bir araya getiren çok öğrencili eğitim platformu.

İlk çalışan ürün dilimi; ortak giriş akışını, rol bazlı öğrenci ve admin panellerini, admin tarafından öğrenci hesabı oluşturmayı, öğrenme yolunu, güvenli C# kural denetimini ve PWA kabuğunu içerir.

Canlı veri katmanı ödeme yöntemi gerektirmeyen Cloudflare Workers + D1 üzerinde çalışır. API yapılandırılmadığında arayüz otomatik olarak yerel tanıtım adaptörüne geçer. Kurulum ayrıntıları için [Ücretsiz Backend Kurulumu](./FREE_BACKEND_SETUP.md) belgesine bak.
