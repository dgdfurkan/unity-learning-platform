# Seçili Playwright şablonları

Bu proje yalnızca kendi kritik akışlarıyla ilgili şablonları taşır:

- `accessibility/`: contrast, keyboard ve screen reader
- `auth/`: login, password reset, RBAC ve session timeout
- `crud/`: admin öğrenci/içerik kayıt işlemleri
- `dashboard/`: data loading ve realtime update
- `forms/`: file upload ve validation
- `onboarding/`: admin tarafından oluşturulan öğrencinin ilk girişi

İlgisiz checkout, e-ticaret, arama, bildirim merkezi ve profil ayar şablonları bilerek dahil edilmemiştir.
